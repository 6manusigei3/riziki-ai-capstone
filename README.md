# Riziki AI

## Overview

Riziki AI is an ethical SACCO lending assistant designed to improve financial inclusion for informal traders while reducing bias in loan approvals.

## Agents

### Scout Agent
Detects financial stress signals and financial literacy needs.

### Guardian Agent
Performs Tier-1 loan screening.

### Hunter Agent
Coordinates human loan officers and prepares briefing packets.

## Ethical Features

- Human-in-the-loop review
- Data sovereignty principles
- Bias monitoring
- Transparent decision support
